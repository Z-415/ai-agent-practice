# ai-agent-practice

学习 AI Agent 的练习代码仓库。每天一个小交付物，代码自带自测。

## 目录

- `exercises/day1.py` ~ `day5.py` —— 每日练习（工程题 + 力扣题，跑一次判分）

## 怎么跑

```bash
git clone git@github.com:Z-415/ai-agent-practice.git
cd ai-agent-practice
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt

python exercises/day5.py      # 跑自测，看还有几题没过
```

## 技术栈

Python 3.13 · 标准库（`json` / `datetime` / `pathlib` / `re` / `argparse` / `logging` / `asyncio`）· Git
